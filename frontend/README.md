# React Frontend - Student Management Portal

Modern, responsive React single-page frontend built with Vite, Tailwind CSS, Lucide Icons, and Axios.

---

## ⚡ Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Open your browser:
   - React UI: [http://localhost:5173](http://localhost:5173)

---

## ⚙️ Backend Configuration

By default, the React app communicates with the .NET Web API running at:
`http://localhost:5252/api/students`

You can customize the API URL by creating a `.env` file:
```env
VITE_API_URL=http://localhost:5252/api/students
```
